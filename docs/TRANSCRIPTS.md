# Transcript issuance

A registrar with explicit permissions issues a private snapshot of released final grades. New issuance finalizes an exact PDF with an identifier, digest and private verification code. Required digital signing must succeed before the request becomes issued. Students view issued records from their records page and finalized PDFs from Academic credentials.

See CREDENTIALS.md for verification, revocation, replacement, historical-record finalization and signing limitations. A digest is not itself a digital signature, and institutional certificate acceptance remains outstanding. Third-party delivery is not yet implemented; destination text does not send a transcript.
