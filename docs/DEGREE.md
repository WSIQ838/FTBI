# Degree audit

Staff configure required course codes for each program. The audit counts positive earned credits from released final grades and approved transfer credits using their recorded equivalent course codes. When several records share a code, it counts the highest credit amount once. It does not infer equivalencies from course titles or external catalogs.

An active student can submit a graduation application when at least one requirement is configured, every required code is satisfied, and total credits meet the program threshold. Staff review applications in administration. Elective groups, catalog-year rules and automated transfer-equivalency evaluation remain unfinished.

Official transcript issuance is a separate registrar workflow with a private snapshot and finalized PDF; see [Transcript issuance](TRANSCRIPTS.md) and [Academic credentials](CREDENTIALS.md) for signing, verification and institutional acceptance limits.
