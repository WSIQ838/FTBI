# Registrar workflows
Generate migrations and run migrate after upgrading. In Django admin, create a StudentProfile linked to an existing user and program. Create RegistrationWindow entries for published courses. Students may register only while active and without a registration hold. Capacity is serialized by a row lock on PostgreSQL; SQLite is development-only and is not appropriate for concurrent registration. Direct administrator enrollment changes can bypass capacity; restrict and supervise admin access.
Admissions is authenticated only: staff create applicant accounts, applicants submit statements and select programs, and staff record decisions in admin. Acceptance does not automatically create a student profile. No public application, official transcript, prerequisite checks, degree audit, waitlists, or registration audit log yet.
