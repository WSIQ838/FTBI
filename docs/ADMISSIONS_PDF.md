# Public admissions and transcript PDF
Public applicant signup is opt-in and requires SMTP plus an explicitly configured HTTPS admissions origin. Accounts remain inactive until a one-time, time-limited email activation token is confirmed by POST. The token expires using Django's password reset timeout. Staff must handle expired registrations and duplicate email ownership questions. Identity verification beyond email remains a staff responsibility. Transcript PDFs remain private. New transcript/diploma artifacts support optional configured signing; legacy dynamically rendered transcripts remain unsigned. See CREDENTIALS.md for exact-artifact and signing limits. Admissions portal letters are separate, unsigned records; see ADMISSION_LIFECYCLE.md for preserved decision wording.
