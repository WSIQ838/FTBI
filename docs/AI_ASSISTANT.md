# Academic assistant
Optional OpenAI Responses API integration: study tutor, instructor drafting and administrative guidance. The application does not provide database records or tools to the model, does not persist chat history, and requests store=false. User consent and role checks apply; this is not a guarantee against users entering personal information. Provider retention, institutional data agreements, cost limits, and academic integrity policies must be reviewed before enabling. The default is disabled. Set FTBI_AI_ENABLED=1, FTBI_AI_KEY and FTBI_AI_MODEL only after approval. Shared rate limiting and real-provider testing remain required. No AI-generated grades, eligibility decisions, or automatic actions.
