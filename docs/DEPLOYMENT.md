# Development container and deployment boundary
The Compose stack is a local development environment using PostgreSQL and Django runserver, exposed on loopback only. It is not production deployment. Create unique secrets outside Git. Do not reuse the example values. Run the test suite against PostgreSQL and generate, review and commit versioned migrations before deployment.
For production use a supported WSGI server, HTTPS reverse proxy, private database networking, managed secrets, restricted staff roles, monitoring, encrypted backups, tested restoration, and a privacy/accessibility/security review. Configure institution-specific grading and registrar policies. MFA, SSO, payment provider integration and AI remain unimplemented. Django admin logging plus login/logout and transcript request events are not a comprehensive audit trail.
