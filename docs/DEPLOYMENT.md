# Deployment candidate
Production Compose provides PostgreSQL, Redis, Gunicorn, a Caddy TLS reverse proxy, readiness probes, and an optional private ClamAV service. The web container is not directly published. The Python setup wizard generates a private .env, configures institution names, and optionally initializes migrations, roles and the first administrator. DNS must resolve to the deployment host for public TLS. The configuration is a candidate, not a completed production deployment. Test in an isolated staging environment first.
Redis is private to the Compose network; do not expose it publicly. Enable the scanner profile and set FTBI_CLAMAV_HOST=scanner only after signature updates and live scanner validation. The proxy caps request bodies at 8 MB. Optional integrations remain disabled until explicitly configured, tested and approved. Backup scheduling, offsite replication and SMTP require operator configuration. Do not deploy real student data before security and privacy acceptance.
