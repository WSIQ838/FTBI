# Release gates
- Versioned migrations and regression tests on SQLite/PostgreSQL.
- Fresh production Compose startup, TLS, readiness, shared-cache and scanner checks.
- Browser/mobile/accessibility and concurrent-user testing.
- Verify Stripe in test mode, reconcile refunds, verify approved SMTP, OIDC and AI providers.
- Encrypted offsite backup and disposable restore drill.
- Independent authorization, vulnerability, privacy and penetration review.
- Institutional signoff on academic, finance, records and retention policies.
- Publish a stable release only when required gates pass. Do not label a candidate as production certified.
