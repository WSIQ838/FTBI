# Timed assessments

The clock starts on first access and uses the earlier of the quiz closing time and session expiry. A configured duration includes the student's extra-time accommodation. An extended closing date can allow access after the ordinary deadline. Each submitted attempt consumes one allowed attempt; accommodations can add up to five. Expired unsubmitted sessions require staff intervention and are not silently reset. Random question selection is saved in the session and stays stable on reload. Question and policy changes are blocked after the first session. See QUIZZES.md for the assessment workflow.
