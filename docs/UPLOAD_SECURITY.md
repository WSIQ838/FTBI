# Extended coursework uploads
The default remains UTF-8 plain text only. Configuring FTBI_CLAMAV_HOST and FTBI_CLAMAV_PORT enables PDF, PNG, JPEG and OOXML documents (.docx, .xlsx, .pptx). Uploads are capped at 5 MB, checked for basic format signatures, and scanned by a private ClamAV daemon using INSTREAM. Scanner errors reject uploads. Basic signature checks and scanning do not prove safety; files remain forced downloads. Keep the scanner on a private trusted network, maintain current definitions, enforce proxy body limits and storage quotas, and validate against known test signatures before enabling. Existing attachments are not rescanned automatically. No public media URLs.
