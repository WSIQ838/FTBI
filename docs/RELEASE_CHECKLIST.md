# Release gates
- Generate and commit reviewed migrations.
- Run the complete test suite on SQLite and PostgreSQL, including concurrency tests.
- Review authorization on every route and administrator permission.
- Validate accessible navigation, forms and errors.
- Configure HTTPS, production WSGI, secrets, rate limits, monitoring and backup scheduling.
- Approve institutional grading, degree, financial, transcript and privacy policies.
- Integrate and test MFA/SSO and any approved payment or AI services.
- Complete a test restore and independent security review.
No real student information until these gates pass.
