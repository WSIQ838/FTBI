# FTBI user guide
## Students
Sign in, open a course, read lessons, submit assignments before deadlines, take published quizzes, and view instructor feedback. Use registration for open sections, records for transcript requests and student services for attendance, grades, degree progress and account balances. Use messages to contact assigned instructors. Payment receipts are subject to staff verification.
## Faculty
Open an assigned course and select Manage course content. Create lessons, assignments and quizzes, configure questions before publishing, and grade submitted work. Current weighted grades exclude ungraded work and require administrator-configured category weights.
## Registrar and staff
Use Django admin with the appropriate institutional group permissions. Maintain student profiles, programs, enrollment, registration windows, released final grades, degree requirements and graduation decisions. Issue transcript snapshots from the transcript queue. Finance reconciles receipts independently; an unverified receipt does not change the ledger.
## Release status
Development preview only. Verify migrations, run all tests, review institutional grading rules, privacy, accessibility, MFA/SSO and deployment controls before real use.
