# Faculty course tools

From an assigned course, open **Manage course content**. Bulk grading supports at most 100 submissions and uses the same grading validation as individual grading. Changes are audited.

**Rubric** defines criteria and point maxima. The grade is earned criterion points divided by possible points, expressed as a percentage. All criteria require valid scores. Rubrics lock after the first submission; copy the course to revise them for a new class.

**Submission policy** sets a total submission limit, late window in hours, and whether graded work may be resubmitted. Without a policy, the original deadline applies and graded work is closed. A permitted resubmission archives previous text, grade, feedback, criterion scores and attachment, then clears the current grade and attachment for fresh review. Each successful text replacement counts as a submission. Attaching a file does not consume an attempt; files cannot change after grading. Students can see the policy and rubric in their course.

**Version history** is available to the owner while actively enrolled in a published course and to its instructor. Previous attachments remain downloadable under the same access controls. History is not editable through the portal.

**Copy course content** requires an empty unpublished target assigned to the same instructor. It copies syllabus, lessons, assignments, rubrics, assignment policies, category weights, questions and quiz timing policies. Assignment and quiz deadlines shift by the requested days. Copied quizzes remain unpublished. Enrollments, submissions, attempts, accommodations and other student records are excluded. Portable import/export remains outstanding.

Students can view submission/grade counts and export visible published calendar events as ICS. Calendar export is a snapshot, not a public feed.
