# FTBI roadmap
## Implemented foundation
Django authentication, admin CRUD, departments, programs, terms, course sections, enrollments, published course access, lessons, text assignments, grading and feedback.
## Next milestones
1. Student profiles, registrar roles and scoped faculty authoring.
2. Course registration, prerequisites, waitlists and academic calendar.
3. Quiz engine, file submissions, weighted gradebook, attendance.
4. Degree audits, GPA, official transcripts, admissions and advising.
5. Tuition, accreditation reporting, messaging, accessible student services.
6. Production hardening: MFA/SSO, audit events, backups and restore tests, HTTPS reverse proxy, privacy review, accessibility testing, monitoring and security review.
No real student records should be entered until deployment and security controls are validated. This repository is public; never commit credentials or student information.
