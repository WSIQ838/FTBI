# Portal interface
Responsive navigation, accessible form focus, skip navigation, and OS-preference dark mode. The shared layout links student services and conditionally displays institutional reporting and administrative navigation. Navigation visibility is not authorization; view permissions remain server-side. Five browser configurations and sampled automated accessibility checks passed in PR #29; comprehensive accessibility, screen-reader and institutional usability review remain required.

See INSTITUTION.md for branding controls, personal timezone/dashboard preferences and scoped search filters.
