# Authenticator MFA
Uses django-otp TOTP devices and session verification with device throttling and replay protection. Users can enroll via Account security, then subsequent sessions require a code. FTBI_REQUIRE_MFA=1 requires enrollment for everyone; FTBI_REQUIRE_STAFF_MFA=1 requires it for staff. Both default off in development; staff enforcement defaults on outside DEBUG. Gate covers authenticated views including Django admin. Lost-device recovery requires a verified institutional identity-recovery procedure and an authorized operator removing the device and revoking existing sessions; no self-service recovery codes yet. Protect the database and backups because TOTP secrets are stored there. MFA enrollment and verification require HTTPS outside development. This implementation requires testing, including password reset, admin login, concurrent attempts and recovery before production.
