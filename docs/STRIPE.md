# Automated card payments
Optional Stripe Checkout supports USD card payment of the current released ledger balance. Signed checkout.session.completed events validate the session ID, currency and amount and post a ledger credit transactionally. Repeated events for an already verified payment are ignored. Manual payment review must never mark Stripe-created requests verified. Multiple checkout sessions may lead to overpayment; finance must reconcile and refund as appropriate. Refunds, disputes, asynchronous payment methods and real-provider testing are outstanding. Enable only after institutional finance approval and test-mode verification. Configure FTBI_STRIPE_ENABLED, STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET and an HTTPS FTBI_PUBLIC_ORIGIN. No card data is collected by FTBI.
