# Production deployment candidate
This configuration is deliberately fail-closed: web startup requires versioned, applied migrations and the release checks. It uses a private PostgreSQL service, Gunicorn, WhiteNoise and a loopback-only port. A trusted HTTPS reverse proxy must overwrite X-Forwarded-Proto and Host, and must not allow clients to set trusted proxy headers. Configure allowed hosts, secrets, database migrations, TLS, rate limiting, backups and monitoring. Do not use with actual student data before tests and independent security/privacy review.
CI runs SQLite and PostgreSQL tests and publishes generated migrations for review. Generated migrations must be committed before production startup. Provider-backed MFA, SSO, AI and automated payments are still release blockers if required.
