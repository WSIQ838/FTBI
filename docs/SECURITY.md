# Security boundary
Authenticated responses disable caching; Django provides CSRF protection and secure cookies outside debug mode. Password validators are enabled. Do not expose the development server. Enforce MFA and SSO through a reviewed identity integration before production; neither is implemented by these changes. Restrict administrative permissions and database access, configure rate limits, HTTPS and monitoring, and validate audit coverage. Backup scripts require PostgreSQL client utilities and secure credential handling. Encrypt backups, restrict access, schedule externally and test restores against an isolated database. Never commit dumps or secrets.
