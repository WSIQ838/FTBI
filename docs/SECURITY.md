# Security boundary
Authenticated responses disable caching; Django provides CSRF protection and secure cookies outside debug mode. Password validators are enabled. Do not expose the development server. TOTP MFA, single-use recovery, optional WebAuthn verification and preprovisioned OIDC integration are implemented; institutional identity-provider validation, physical-device/domain validation and independent MFA review remain required before production. See MFA.md, MFA_RECOVERY.md and ACCOUNT_SECURITY.md. Restrict administrative permissions and database access, configure rate limits, HTTPS and monitoring, and validate audit coverage. Backup scripts require PostgreSQL client utilities and secure credential handling. Encrypt backups, restrict access, schedule externally and test restores against an isolated database. Never commit dumps or secrets.
