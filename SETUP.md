# FTBI setup candidate
The local operator wizard is scripts/setup.py. It creates a private .env without overwriting existing secrets and can initialize Docker, migrations, roles and a first administrator. Use --help to see options. Development uses loopback HTTP; production candidate uses Caddy TLS and PostgreSQL. The production DNS and infrastructure must be ready before startup. See docs/DEPLOYMENT.md and docs/RELEASE_GATES.md. Faculty author courses through their assigned-course interface, not broad Django admin permissions.
