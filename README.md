# FTBI College Management System
Development preview of a Django-based college LMS and SIS. Includes courses, assignments, grading, admissions, registration, academic records, basic student services, and administrative record management.

See [setup](SETUP.md), [registrar workflows](docs/REGISTRAR.md), [student services](docs/SERVICES.md) and [testing](docs/TESTING.md).

**Not production-ready.** Initial migrations need generation and review, tests need execution, and privacy/security controls need validation. Do not enter real student records. Dockerfile is for development only. Remaining functionality includes advanced assessments, full faculty authoring, weighted gradebook, official transcripts, degree audits, payment processing, SSO/MFA, audit trails, and production deployment.

Basic auto-scored multiple-choice quizzes: [documentation](docs/QUIZZES.md).
